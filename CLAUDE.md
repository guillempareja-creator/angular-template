# CLAUDE.md — App Template

> **Este repositorio es un cascarón (template), no una aplicación.** La primera tarea sobre él es
> convertirlo en un proyecto real: ver [`.github/skills/new-project/SKILL.md`](.github/skills/new-project/SKILL.md)
> o el comando `/new-project`.

> **Definition of Done:** ninguna tarea está terminada hasta que **`npm run check` pasa en verde**
> de principio a fin (formato, lints, arquitectura, tipos, tests con cobertura, build y e2e).
> Nunca se relaja un gate para conseguirlo: se arregla el código o se consulta al humano.

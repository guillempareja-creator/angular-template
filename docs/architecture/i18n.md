# Textos e i18n

> Regla agnóstica: **cero texto visible hardcodeado**. La librería concreta
> (Angular: `@ngx-translate`) y su uso están en
> [`../stack/angular.md`](../stack/angular.md#8-i18n). Paso a paso: skill
> `i18n`.

## 1. Qué cuenta como texto visible

Todo lo que lee el usuario o una tecnología de asistencia: títulos, etiquetas,
`placeholder`, `aria-label`, `alt`, `title`, botones, cabeceras de tabla,
mensajes de validación, notificaciones, textos de carga y de estado vacío. Todo
sale del fichero de traducciones.

## 2. Ficheros

Un JSON por idioma en `src/assets/i18n/` (hoy `es.json`). Las claves van en
**inglés y camelCase**; los valores, en el idioma del usuario. Interpolación con
`{{param}}`.

```json
{
  "common": { "accept": "Aceptar", "cancel": "Cancelar", "close": "Cerrar" },
  "app": { "name": "App Template" },
  "main": {
    "welcomeMessage": "¡Hola! Bienvenido a {{appName}}",
    "exampleTitle": "Llamada de ejemplo a la API"
  }
}
```

## 3. Convención de claves

```
{domain}.{component}.{grupo}.{clave}
```

- Solo los niveles necesarios: dominio de una sola pantalla → `{domain}.{clave}`
  (`main.exampleTitle`).
- Componentes de `shared/` usan su nombre como raíz (`header.menu.title`).
- Raíces transversales: `common` (acciones y textos compartidos: aceptar,
  cancelar, cerrar…) y `app` (datos de la aplicación; `app.name` lo sustituye
  `npm run rename`).
- Grupos semánticos habituales: `columns`, `buttons`, `tabs`, `modal`,
  `filters`, `menu`, `steps`, `notifications`. Textos únicos sin grupo: `title`,
  `noResults`.
- **Reutilizar `common.*`** antes de crear una clave: nunca "Cancelar" duplicado
  por dominio.
- Las claves espejan los `id` de los elementos ([`overview.md`](overview.md)
  §5).
- Al borrar un componente o dominio, se borran sus claves.

## 4. Uso

- En plantillas: el pipe/filtro de traducción, siempre con _binding_ (nunca
  interpolación dentro de atributos).
- En código: un helper **tipado** que devuelve siempre `string` (la clave si
  falta la traducción). Nunca la API de la librería que devuelve `any`.
- La app no se pinta hasta que el idioma por defecto está cargado, así que
  traducir en código es seguro desde el primer momento.

## 5. Tests

- **Unitarios**: el proveedor de traducciones sin cargador devuelve **la
  clave**, así que se asertan claves (`'main.exampleLoading'`), no textos.
- **E2E**: ven el texto real del idioma (`'Llamada de ejemplo a la API'`).
